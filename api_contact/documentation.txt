Pour que le formulaire de contact fonctionne, il faut copier les fichiers de ce repertoire dans la partie backend en enlevant l'extension txt de leur nom.

Copier cette ligne dans app.py
    mail.init_app(app)

Renseigner les valeurs de ces constantes dans le fichier config.py
    MAIL_SERVER = ''
    MAIL_PORT = 25
    MAIL_USE_TLS = False
    MAIL_USE_SSL = False
    MAIL_DEFAULT_SENDER = ""
    """ Destinataire du formulaire """
    MAIL_RECEIVER = ""
    MAIL_ASCII_ATTACHMENTS = False
    MAIL_USERNAME = ""
    RECAPTCHA_SECRET_KEY = ""
